![Código para Protesto](01_parametro.png){width=60%}

### ▌CÓDIGOS

Digite no **VALOR DO PARÂMETRO** o código da opção desejada.

| Código | Descrição |
| --- | --- |
| **01** | Protestar Dias Corridos. |
| **02** | Protestar Dias Úteis. |
| **03** | Não Protestar. |
| **04** | Protestar Fim Falimentar - Dias Úteis. |
| **05** | Protestar Fim Falimentar - Dias Corridos. |
| **08** | Negativação sem Protesto. |
| **09** | Cancelamento Protesto Automático. |
