# Faturas - Bloquear importação de PREFAT com diferença de documentos

- ID: PO-A-419
- Caminho: 🛟 BASE DE CONHECIMENTO > EMPRESA > CONFIGURAÇÕES > PARÂMETROS > Faturas - Bloquear importação de PREFAT com diferença de documentos

![Bloquear PREFAT com diferença de documentos](00_banner.png){width=100%}

> **MÓDULO:** FATURAS

> **LOCALIZAÇÃO:** EMPRESA -> CONFIGURAÇÕES -> DADOS & PARÂMETROS

Se esta opção estiver marcado como **SIM**, ao realizar a importação do arquivo PREFAT, caso haja diferença de quantidade de documentos no arquivo quando comparados com quantidades totais dos documentos das faturas, um erro será emitido na tela, impedindo a criação de uma fatura cadastrada.

![Bloquear importação de PREFAT com diferença de documentos](01_invoice_prefat_document_diff.png){width=60%}

### ▌OPÇÕES

| Opção | O que faz |
| --- | --- |
| **SIM** | Ativa a regra descrita acima. |
| **NÃO** *(padrão)* | Não aplica a regra. |
