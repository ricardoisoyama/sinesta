> **MÓDULO:** FATURAS

> **LOCALIZAÇÃO:** EMPRESA -> CONFIGURAÇÕES -> DADOS & PARÂMETROS

Se esta opção estiver marcado como **SIM**, ao realizar a emissão de uma fatura, se o cliente possuir e-mail de faturamento configurado, este será utilizado para que o e-mail contendo a fatura do cliente seja enviado de forma automática pelo sistema.

![E-mail Automático ao Emitir](01_auto_send_invoice_email.png){width=60%}

### ▌OPÇÕES

| Opção | O que faz |
| --- | --- |
| **SIM** | Ativa a regra descrita acima. |
| **NÃO** *(padrão)* | Não aplica a regra. |
