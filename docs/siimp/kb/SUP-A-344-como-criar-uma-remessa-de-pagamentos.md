## 📔 PASSO A PASSO

1️⃣ Acessar **FINANCEIRO** ➡ **OPÇÕES BANCÁRIAS** ➡️ **CNAB DE TRANSAÇÕES:**

![](image-20220914-194345.png)

2️⃣ Para criar uma nova remessa, clicamos no ícone +NOVO.

![](image-20220914-195731.png)

3️⃣ Em seguida, conseguimos realizar a busca pelos documentos necessários através dos filtros disponíveis na tela e clicar em **BUSCAR** para que o sistema conclua a pesquisa. Depois de encontrado os documentos desejados, basta clicar em **SALVAR E EMITIR**.

![](image-20220915-141215.png)

4️⃣ Com isso, o status da sua nova transação será modificado para **EMITIDO**. A partir desse momento, é possível realizar a baixa do arquivo.

![](image-20220915-141800.png)
