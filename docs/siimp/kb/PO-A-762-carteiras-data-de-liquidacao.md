> **MÓDULO:** CARTEIRAS

> **LOCALIZAÇÃO:** EMPRESA -> CARTEIRAS -> PARÂMETROS -> CNAB

Define qual data o sistema usa como **DATA DE LIQUIDAÇÃO** na leitura do retorno do CNAB.

![Data de Liquidação](01_parametro.png){width=60%}

### ▌OPÇÕES

| Opção | O que faz |
| --- | --- |
| **DATA DE PAGAMENTO** *(padrão)* | Usa a data de pagamento informada no retorno. |
| **DATA DE CRÉDITO** | Usa a data de crédito informada no retorno. |
