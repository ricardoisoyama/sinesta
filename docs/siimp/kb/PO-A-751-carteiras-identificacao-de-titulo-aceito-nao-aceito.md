> **MÓDULO:** CARTEIRAS

> **LOCALIZAÇÃO:** EMPRESA -> CARTEIRAS -> PARÂMETROS -> BOLETO

Define se o título é identificado como **ACEITO** ou **NÃO ACEITO** na remessa.

![Identificação de Título Aceito / Não Aceito](01_parametro.png){width=60%}

### ▌CÓDIGOS

Digite no **VALOR DO PARÂMETRO** o código da opção desejada.

| Código | Descrição |
| --- | --- |
| **A** | Aceite. |
| **N** | Não Aceite. |
