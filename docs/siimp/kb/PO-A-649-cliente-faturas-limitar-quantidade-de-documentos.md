# Cliente - Faturas - Limitar Quantidade de Documentos

- Caminho: 🛟 BASE DE CONHECIMENTO > PESSOAS > Parâmetros > Cliente - Faturas - Limitar Quantidade de Documentos

> **MÓDULO:** FATURAS

> **LOCALIZAÇÃO:** PESSOAS -> PARÂMETROS

> **CLASSIFICAÇÃO:** CLIENTE

Informe no campo abaixo um valor limite para quantidade de documentos ao gerar uma fatura. Ao salvar uma fatura, o sistema irá impedir a ação caso a quantidade de documentos existentes ultrapasse o valor informado neste parâmetro.

![Limitar Quantidade de Documentos](01_grouped_invoice_limit_by_document_count.png){width=60%}

**VALOR:** Número inteiro, a partir de 1. Sem valor, fica *Nenhum Limitador*.
