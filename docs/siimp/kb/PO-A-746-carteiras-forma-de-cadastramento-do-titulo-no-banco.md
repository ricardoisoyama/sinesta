> **MÓDULO:** CARTEIRAS

> **LOCALIZAÇÃO:** EMPRESA -> CARTEIRAS -> PARÂMETROS -> BOLETO

Define a forma como o título será cadastrado no banco *(com ou sem registro)*.

![Forma de Cadastramento do Título no Banco](01_parametro.png){width=60%}

### ▌CÓDIGOS

Digite no **VALOR DO PARÂMETRO** o código da opção desejada.

| Código | Descrição |
| --- | --- |
| **1** | Com Cadastramento *(Cobrança Registrada)*. |
| **2** | Sem Cadastramento *(Cobrança sem Registro)*. |
| **3** | Com Cadastramento / Recusa do Débito Automático. |
