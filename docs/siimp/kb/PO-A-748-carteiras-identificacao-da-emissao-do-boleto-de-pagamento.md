> **MÓDULO:** CARTEIRAS

> **LOCALIZAÇÃO:** EMPRESA -> CARTEIRAS -> PARÂMETROS -> BOLETO

Define quem **EMITE** o boleto de pagamento: o banco, o cliente ou os dois.

![Identificação da Emissão do Boleto de Pagamento](01_parametro.png){width=60%}

### ▌CÓDIGOS

Digite no **VALOR DO PARÂMETRO** o código da opção desejada.

| Código | Descrição |
| --- | --- |
| **1** | Banco Emite. |
| **2** | Cliente Emite. |
| **3** | Banco Pré-emite e Cliente Complementa. |
| **4** | Banco Reemite. |
| **5** | Banco Não Reemite. |
| **6** | Banco Emitente - Aberta. |
| **7** | Banco Emitente - Auto-envelopável. |
| **8** | Escritural. |

>
> <span style="color:red;">*Use os códigos conforme o manual de cobrança do seu banco.*</span>
