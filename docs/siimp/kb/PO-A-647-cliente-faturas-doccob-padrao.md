> **MÓDULO:** FATURAS

> **LOCALIZAÇÃO:** PESSOAS -> PARÂMETROS

> **CLASSIFICAÇÃO:** CLIENTE

Se este parâmetro estiver configurado, ao emitir uma fatura para este cliente, o sistema irá gerar um **DOCCOB** automaticamente e deixá-lo disponível para download na página web da fatura. Dessa forma, quando o cliente acessar a fatura para baixar os boletos, XMLs e DACTes dos CT-es, ele também poderá baixar o arquivo DOCCOB da fatura.

![DOCCOB Padrão](01_doccob.png){width=60%}

**VALOR:** Lista dos layouts de DOCCOB disponíveis no sistema. Sem seleção, fica *Nenhum*.
