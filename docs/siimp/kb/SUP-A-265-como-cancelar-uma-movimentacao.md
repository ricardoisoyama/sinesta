## 📔 PASSO A PASSO

1️⃣ Acessar **FINANCEIRO** ➡ **MOVIMENTAÇÕES** ➡ **MOVIMENTAÇÕES**:

![](image-20220803-114722.png)

2️⃣ Selecionar a movimentação que deseja realizar o cancelamento com dois cliques, e o sistema irá abrir uma nova tela referente a movimentação selecionada. 

3️⃣ Para realizar o cancelamento, basta clicar no ícone **CANCELAR**.

![](image-20220803-115446.png)

4️⃣ O sistema irá abrir uma tela de confirmação sobre o cancelamento da movimentação, informando que essa ação não poderá ser revertida. E ao confirmar, o sistema irá realizar o cancelamento, conforme desejado.

![](image-20220803-123722.png)

***ATENÇÃO:** Para realizar o cancelamento de uma movimentação, o status deve estar “**EM ABERTO**”. Caso esteja **LIQUIDADA**, é necessário **REABRIR** a movimentação, para que o status volte para **EM ABERTO** e seja possível prosseguir com o cancelamento.*
