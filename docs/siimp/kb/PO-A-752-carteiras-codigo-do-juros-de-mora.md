### ▌CÓDIGOS

Digite no **VALOR DO PARÂMETRO** o código da opção desejada.

| Código | Descrição |
| --- | --- |
| **1** | Valor por Dia. |
| **2** | Taxa Mensal. |
| **3** | Isento. |
