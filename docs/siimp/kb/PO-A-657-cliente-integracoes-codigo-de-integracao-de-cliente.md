> **MÓDULO:** INTEGRAÇÕES

> **LOCALIZAÇÃO:** PESSOAS -> PARÂMETROS

> **CLASSIFICAÇÃO:** CLIENTE

Código do cliente em sistemas terceiros/agregados que fazem conexão com o sistema TMS a fim de executar operações onde este cliente é mencionado.

Atualmente, este campo é somente utilizado para envio de informações através de arquivos **EDI**.

![Código de Integração de Cliente](01_parameter_bdc_customer_cod.png){width=60%}

**VALOR:** Texto livre, com até 15 caracteres.
