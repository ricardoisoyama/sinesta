> **MÓDULO:** CARTEIRAS

> **LOCALIZAÇÃO:** EMPRESA -> CARTEIRAS -> PARÂMETROS -> INSTRUÇÕES

Quando marcado como **SIM**, a carteira fica disponível para **ORDEM DE PAGAMENTO**.

![Carteira disponível para ordem de pagamento](01_parametro.png){width=60%}

### ▌OPÇÕES

| Opção | O que faz |
| --- | --- |
| **NÃO** *(padrão)* | Não aplica a regra. |
| **SIM** | Ativa a regra descrita acima. |
