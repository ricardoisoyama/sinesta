> **MÓDULO:** CARTEIRAS

> **LOCALIZAÇÃO:** EMPRESA -> CARTEIRAS -> PARÂMETROS -> PAGAMENTO

Define o **TIPO DE SERVIÇO** informado no CNAB de pagamento.

![Tipo de Serviço](01_parametro.png){width=60%}

### ▌CÓDIGOS

Digite no **VALOR DO PARÂMETRO** o código da opção desejada.

| Código | Descrição |
| --- | --- |
| **1** | Pagamento Fornecedor. |
| **2** | Pagamento de Contas, Tributos e Impostos. |
| **3** | Pagamento Salários. |
| **4** | Pagamento de honorários. |
| **5** | Pagamento de bolsa auxílio. |
