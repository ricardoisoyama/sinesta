# Minutas - Liberar Cancelamento/Inutilização de Minutas em uma Fatura

> **MÓDULO:** MINUTAS

> **LOCALIZAÇÃO:** EMPRESA -> CONFIGURAÇÕES -> DADOS & PARÂMETROS

Se esta opção estiver marcada como **SIM**, o sistema irá permitir que o usuário que possua acesso direto à listagem de Minutas Comuns, de Serviço, Agendamento, Fechamento e/ou AET realize o cancelamento e/ou inutilização daquelas que já estiverem em uma fatura.

Caso a opção esteja marcada como **NÃO**, o sistema impedirá esta ação, exigindo que a fatura seja previamente cancelada antes do cancelamento/inutilização da Minuta desejada.

![Liberar Cancelamento/Inutilização de Minutas em uma Fatura](01_can_income_cancel_in_invoice.png){width=60%}

### ▌OPÇÕES

| Opção | O que faz |
| --- | --- |
| **SIM** *(padrão)* | Ativa a regra descrita acima. |
| **NÃO** | Não aplica a regra. |
