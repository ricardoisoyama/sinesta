> **MÓDULO:** PROGRAMAÇÃO DE CARGA

> **LOCALIZAÇÃO:** EMPRESA -> CONFIGURAÇÕES -> DADOS & PARÂMETROS

Se esta opção estiver marcada como **SIM**, então ao realizar o encerramento de uma **PROGRAMAÇÃO DE CARGA**, o sistema tentará gerar uma fatura automaticamente *(caso a programação ainda não possua faturas vinculadas)*, considerando o **PERFIL DE FATURAMENTO** atrelado ao cliente da programação.

![Gerar Fatura Automaticamente](01_process_generate_invoice_automatically.png){width=60%}

### ▌OPÇÕES

| Opção | O que faz |
| --- | --- |
| **SIM** | Ativa a regra descrita acima. |
| **NÃO** *(padrão)* | Não aplica a regra. |
