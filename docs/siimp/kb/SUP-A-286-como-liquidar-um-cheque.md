## 📔 PASSO A PASSO

1️⃣ Acesse o sistema e vá em **FINANCEIRO** ➡ **CHEQUES**

![](image-20220811-142222.png)

Lembrando que, para **LIQUIDAR** um cheque, o mesmo precisa estar com o status **EMITIDO**



2️⃣ Selecione um Cheque e de dois cliques para abri-lo

![](image-20220811-142418.png)![](image-20220811-142509.png)

3️⃣ Clique no botão **LIQUIDAR**

![](image-20220811-142552.png)

4️⃣ Para Liquidar o cheque, é necessário inserir a **data de compensação**

![](image-20220811-142726.png)

5️⃣ Confirme a ação que aparecerá na tela

![](image-20220811-142812.png)

o status será alterado para **LIQUIDADO**

![](image-20220811-142847.png)
