> **MÓDULO:** FATURAS

> **LOCALIZAÇÃO:** PESSOAS -> PARÂMETROS

> **CLASSIFICAÇÃO:** CLIENTE

Se este parâmetro estiver configurado, ao emitir uma fatura para este cliente, o sistema irá gerar um **CONEMB** automaticamente e deixá-lo disponível para download na página web da fatura. Dessa forma, quando o cliente acessar a fatura para baixar os boletos, XMLs e DACTes dos CT-es, ele também poderá baixar o arquivo CONEMB dos CT-es contidos da fatura.

![CONEMB Padrão](01_conemb.png){width=60%}

**VALOR:** Layouts de CONEMB disponíveis: CONEMB 2.0 - SIPROQUIM, CONEMB 3.1 - GoodYear, CONEMB 3.1 - GTM e CONEMB 3.1 - Proceda. Sem seleção, fica *Nenhum*.
