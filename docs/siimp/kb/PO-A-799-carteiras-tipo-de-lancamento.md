> **MÓDULO:** CARTEIRAS

> **LOCALIZAÇÃO:** EMPRESA -> CARTEIRAS -> PARÂMETROS -> PAGAMENTO

Define o **TIPO DE LANÇAMENTO** informado no CNAB de pagamento.

![Tipo de Lançamento](01_parametro.png){width=60%}

### ▌CÓDIGOS

Digite no **VALOR DO PARÂMETRO** o código da opção desejada.

| Código | Descrição |
| --- | --- |
| **1** | Crédito em Conta Corrente. |
| **4** | Cartão Salário. |
| **5** | Crédito em Conta Poupança. |
| **6** | Pagamento de Contas de Consumo. |
| **7** | Liquidação de Títulos do Próprio Banco. |
| **8** | Pagamento de Títulos de Outros Bancos. |
| **9** | TED - Outra Titularidade. |
| **10** | TED - Mesma Titularidade. |
| **11** | DOC - Outra Titularidade. |
| **12** | DOC - Mesma Titularidade. |
| **13** | PIX - Transferência. |
| **14** | PIX - QR Code. |
| **15** | DARF PIS. |
| **16** | DARF COFINS. |
| **17** | DARF Desoneração. |
| **18** | GARE SP ICMS. |
| **19** | FGTS. |
| **20** | Tributos com Código de Barras. |
