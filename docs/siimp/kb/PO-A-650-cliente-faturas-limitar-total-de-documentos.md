# Cliente - Faturas - Limitar Total de Documentos

- ID: PO-A-650
- Caminho: 🛟 BASE DE CONHECIMENTO > PESSOAS > Parâmetros > Cliente - Faturas - Limitar Total de Documentos

> **MÓDULO:** FATURAS

> **LOCALIZAÇÃO:** PESSOAS -> PARÂMETROS

> **CLASSIFICAÇÃO:** CLIENTE

Informe no campo abaixo um valor limite para o total de documentos ao gerar uma fatura. Ao salvar uma fatura, o sistema irá impedir a ação caso o valor total dos documentos existentes ultrapasse o valor informado neste parâmetro.

![Limitar Total de Documentos](01_grouped_invoice_limit_by_document_total.png){width=60%}

**VALOR:** Número com até 2 casas decimais, a partir de 0,01. Sem valor, fica *Nenhum Limitador*.
