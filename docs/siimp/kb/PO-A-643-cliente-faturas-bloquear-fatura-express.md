> **MÓDULO:** FATURAS

> **LOCALIZAÇÃO:** PESSOAS -> PARÂMETROS

> **CLASSIFICAÇÃO:** CLIENTE

Se esta opção estiver marcada como **SIM**, o sistema irá impedir que os CT-es/Minutas deste cliente sejam exibidas na listagem de documentos do módulo **FATURA EXPRESS**, obrigando os usuários do sistema a realizarem o faturamento deste cliente de forma manual.

![Bloquear Fatura Express](01_parameter_block_invoice_generator.png){width=60%}

### ▌OPÇÕES

| Opção | O que faz |
| --- | --- |
| **SIM** | Ativa a regra descrita acima. |
| **NÃO** *(padrão)* | Não aplica a regra. |
