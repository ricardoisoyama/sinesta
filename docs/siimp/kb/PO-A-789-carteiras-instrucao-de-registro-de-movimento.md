> **MÓDULO:** CARTEIRAS

> **LOCALIZAÇÃO:** EMPRESA -> CARTEIRAS -> PARÂMETROS -> INTERCÂMBIO BANCÁRIO

Define se os registros do CNAB de intercâmbio bancário são efetivados direto ou passam por aprovação prévia no banco.

> <span style="background-color: #c0392b; color: white; padding: 3px 5px; border-radius: 4px">**PONTO DE ATENÇÃO**</span>
>
> <span style="color:red;">*Se o parâmetro não for preenchido corretamente, o banco trata o registro como **PENDENTE DE APROVAÇÃO**.*</span>

![Instrução de registro de movimento](01_parametro.png){width=60%}

### ▌CÓDIGOS

Digite no **VALOR DO PARÂMETRO** o código da opção desejada. Quando vazio, vale o padrão **9 - PENDENTE DE AUTORIZAÇÃO**.

| Código | Descrição |
| --- | --- |
| **0** | Liberação automática. |
| **9** | Pendente de aprovação. |
