> **MÓDULO:** CARTEIRAS

> **LOCALIZAÇÃO:** EMPRESA -> CARTEIRAS -> PARÂMETROS -> BOLETO

Define como o boleto é **DISTRIBUÍDO** ao pagador.

![Identificação da Distribuição](01_parametro.png){width=60%}

### ▌CÓDIGOS

Digite no **VALOR DO PARÂMETRO** o código da opção desejada.

| Código | Descrição |
| --- | --- |
| **1** | Banco Emite. |
| **2** | Cliente Emite. |
| **3** | Banco envia e-mail. |
| **4** | Banco envia SMS. |
| **P** | Banco registra e cliente distribui boleto com QR Code PIX. |
| **Q** | Banco registra e distribui boleto com QR Code PIX. |

>
> <span style="color:red;">*Use os códigos conforme o manual de cobrança do seu banco.*</span>
