> **MÓDULO:** CARTEIRAS

> **LOCALIZAÇÃO:** EMPRESA -> CARTEIRAS -> PARÂMETROS -> BOLETO

Define o código de **BAIXA E DEVOLUÇÃO** do boleto.

![Código para Baixa / Devolução](01_parametro.png){width=60%}

### ▌CÓDIGOS

Digite no **VALOR DO PARÂMETRO** o código da opção desejada.

| Código | Descrição |
| --- | --- |
| **1** | Baixar / Devolver. |
| **2** | Não Baixar / Não Devolver. |
| **3** | Cancelar Prazo para Baixa / Devolução. |
