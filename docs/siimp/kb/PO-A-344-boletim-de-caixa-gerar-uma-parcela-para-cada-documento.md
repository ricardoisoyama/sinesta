> **MÓDULO:** BOLETIM DE CAIXA

> **LOCALIZAÇÃO:** EMPRESA -> CONFIGURAÇÕES -> DADOS & PARÂMETROS

Se esta opção estiver marcada como **SIM**, ao gerar uma movimentação pelo Boletim de Caixa, cada documento será vinculado a uma parcela.

![Gerar uma parcela para cada documento](01_generate_parcels_in_cash_report_transaction.png){width=60%}

| Opção | O que faz |
| --- | --- |
| **SIM** | Ativa a regra descrita acima. |
| **NÃO** *(padrão)* | Não aplica a regra. |
