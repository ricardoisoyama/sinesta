## 📔 PASSO A PASSO

A tela de intercâmbio possui um cabeçalho, onde é especificada a carteira e a data de agendamento do pagamento, e uma aba com as parcelas que o usuário deseja realizar o pagamento.

![](image-20221128-190645.png)

Descritivo dos campos:

* **CARTEIRA:** a carteira definirá a empresa que está emitindo o arquivo de remessa e todos os dados bancários vinculados.
* **DATA DE PAGAMENTO:** data que o usuário deseja que a ação seja executada.
* **TIPO DE REMESSA:** atualmente temos apenas a remessa para pagamentos.
* **MOVIMENTAÇÕES:** lista de movimentações a pagar, seja transferência, boleto, conta de consumo, PIX ou tributos.

Para adicionar as parcelas, é possível selecionar através do botão **SELECIONAR** ou pesquisar pelos campos de código digitável, data de criação, data de vencimento, data de competência e cliente/credor.

Ao adicionar uma movimentação, o campo **AÇÕES** será adicionado. Ele será responsável por indicar o que o usuário deseja fazer com aquele pagamento (incluir, alterar, cancelar, etc.). Hoje o sistema possui apenas a opção de **INCLUIR**.

Caso o usuário queira alterar esse campo, basta dar dois cliques na linha ou selecionar uma ou mais parcelas e indicar **AÇÃO PADRÃO** no rodapé.

![](image-20230531-183119.png)
