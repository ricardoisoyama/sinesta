# **🗒️ INTRODUÇÃO**

Guia para faturamento direto na tela de Minuta Comum. 

Este procedimento permite a realização do faturamento diretamente pela tela de Minuta Comum, eliminando a necessidade de alternar entre diferentes telas e simplificando o processo para maior agilidade e eficiência.

## 📔 PASSO A PASSO



**1)** Acessar **EMISSÃO** ➡ **MINUTA COMUM**:

![](image.png){width=70%}

**2)** É possível realizar o faturamento de uma ou mais minutas de uma única vez.

Sendo assim, selecionar quais minutas deseja faturar e selecionar a opção **FATURAR**.

![](image1.png){width=70%}

* **MANUAL:** Realiza o faturamento da minuta selecionada de forma manual, precisando preencher a fatura com as informações básicas.

Após o preenchimento da **CARTEIRA**, **FORMA PAGTO**, **PARCELAS**, **A CADA**, **PERÍODO**, é necessário clicar em **GERAR PARCELAS**. Somente com essas informações preenchidas, o sistema irá habilitar a opção de **SALVAR & EMITIR**.

![](image2.png){width=70%}

* **INDIVIDUAL:** Mesmo quando selecionado várias minutas, é gerado um faturamento para cada uma delas individualmente.

Dessa forma, é possível realizar o faturamento de várias minutas com tomadores distintos. Preenchendo os campos em destaque, a fatura já carrega todas as informações básicas, sendo necessário apenas **SALVAR & EMITIR**.

![](image4.png){width=70%}

* **AGRUPADO:** Quando o tomador das minutas forem o mesmo, é possível selecionar todos os documentos e criar apenas uma única fatura.

Preenchendo os campos em destaque, a fatura já carrega todas as informações básicas, sendo necessário apenas **SALVAR & EMITIR**.

![](image5.png){width=70%}
