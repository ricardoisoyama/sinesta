> **MÓDULO:** PROGRAMAÇÃO DE CARGA

> **LOCALIZAÇÃO:** EMPRESA -> CONFIGURAÇÕES -> DADOS & PARÂMETROS

Se este parâmetro estiver ativado, ao realizar o faturamento de uma **PROGRAMAÇÃO DE CARGA** através da opção existente na própria programação, o sistema irá copiar os anexos para a **FATURA**, no momento em que ela for gerada, deixando-os públicos e visíveis para o cliente no **FATURA WEB**.

PS.: A única exceção são os eventos, que só serão espelhados para a fatura se eles forem públicos também.

Abaixo, selecione em quais módulos o sistema deverá copiar os anexos para a fatura.

![Vincular Anexos ao Faturar](01_invoice_process_bind_attachments.png){width=60%}

### ▌OPÇÕES

**VALOR:** permite marcar mais de uma opção.

| Opção | O que faz |
| --- | --- |
| **PROG. CARGA** | Copia os anexos da Programação de Carga. |
| **PROG. VIAGEM** | Copia os anexos da Programação de Viagem. |
| **EVENTOS** | Copia os anexos dos eventos públicos. |

Sem seleção, o sistema usa *PADRÃO: NÃO COPIAR*.
