> **MÓDULO:** PAGAMENTOS

> **LOCALIZAÇÃO:** EMPRESA -> CONFIGURAÇÕES -> DADOS & PARÂMETROS

Se esta opção estiver marcada como **SIM**, ao realizar o adiantamento/liquidação de um pagamento, o sistema irá lançar uma movimentação no financeiro com o status **LIQUIDADA**.

![Liquidar Pagamentos no Financeiro](01_setpay_advanced_payment.png){width=60%}

### ▌OPÇÕES

| Opção | O que faz |
| --- | --- |
| **SIM** *(padrão)* | Ativa a regra descrita acima. |
| **NÃO** | Não aplica a regra. |
