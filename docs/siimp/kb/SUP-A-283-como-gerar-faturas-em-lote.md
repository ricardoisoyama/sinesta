## 📔 PASSO A PASSO



1️⃣ Clique em **Financeiro > Fatura Express.**

![](image-20220803-203743.png)

2️⃣ Clique em **Novo.**

![](image-20220803-203934.png)

3️⃣ Na parte de **Informações da Fatura** preencha os campos abaixo referente a emissão das faturas. 

* **EMPRESA:** caso tenha mais de um CNPJ confirme se a empresa está correta. 

* **CARTEIRA:** selecione a carteira.

* **TIPO:** 

  * **SIMPLES:** o sistema vai acatar o vencimento que for preenchido no campo vencimento.
  * **PERFIL:** o sistema irá aplicar o vencimento conforme o perfil de faturamento atrelado ao cliente. 

* **FORMA DE PGTO:** selecione a forma de pagamento.

* **VENCIMENTO:** preencha o vencimento. (Lembrando que se o cliente tiver o perfil de faturamento vinculado ao cadastro dele, será aplicado o vencimento conforme o perfil).

* **DATA DE EMISSÃO:** o sistema preenche automaticamente.

* **PARCELAS, A CADA E PERÍODO:** altere caso deseje parcelar. 

![](image-20220803-204326.png)

4️⃣ Na parte **Pesquisa documentos**, utilize alguns dos filtros abaixo para buscar os documentos para faturar. 

* **EMPRESA:** selecione a empresa pela qual foi emitido o documento. (Nesse campo é possível selecionar várias empresas ao mesmo tempo). 
* **PERFIL DE FAT:** é possível buscar os documentos através do perfil de faturamento. 
* **CTe:** selecione os status que deseja faturar. 
* **MINUTA:** selecione os status que deseja faturar. (É possível faturar CTes e Minutas junto).
* **DE: e ATÉ:** preencha o período dos documentos que deseja buscar. 

![](image-20220803-205516.png)

5️⃣ Após o sistema trazer os documentos, selecione os que deseja faturar e clique em **gerar selecionados.** 

(Caso não deseje faturar algum cliente, basta selecionar e apertar o botão **Delete** do teclado). 

![](image-20220803-211112.png)

6️⃣ Clique em **Sim** para confirmar. 

![](image-20220803-211437.png)

7️⃣ Após o passo acima, o sistema vai cadastrar as faturas, trazendo a mensagem de **Sucesso** na coluna gerado, os **número da fatura** na coluna N° Fatura. 

![](image-20220803-211800.png)

8️⃣ Para emitir as faturas, **selecione** e clique em **Emitir.** 

![](image-20220803-211914.png)

9️⃣ Clique em **Sim** para confirmar. 

![](image-20220803-211940.png)

🔟 Para consultar a emissão, basta verificar na coluna **Status** se está como **Emitida.** 

![](image-20220803-212039.png)

Na parte inferior da tela, possui os botões para enviar por **email** ou **imprimir** as faturas. 

![](image-20220803-212241.png)
