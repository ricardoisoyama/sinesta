## 📔 PASSO A PASSO

1️⃣ Acesse o sistema e vá em **FINANCEIRO** ➡ **CHEQUES**

![](image-20220811-135132.png)

Lembrando que para cancelar um cheque, o mesmo precisa estar com o Status **EMITIDO.**



2️⃣ Selecione o cheque emitido e dê dois clicks para abri-lo

![](image-20220811-135359.png)![](image-20220811-141004.png)

3️⃣ clique no botão **Cancelar** 

![](image-20220811-141211.png)

4️⃣ Confirme a ação que aparecerá na tela

![](image-20220811-141321.png)![](image-20220811-141336.png)

O status será alterado para **CANCELADO**
