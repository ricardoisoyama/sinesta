Se esta opção estiver marcada como **SIM**, ao realizar a emissão de um boleto para este cliente, o sistema irá instruir no arquivo CNAB de remessa correspondente que o protesto dos boletos deste cliente devem ser sustados.

![Sustar Protesto](01_ignore_boleto_protest.png){width=60%}

### ▌OPÇÕES

| Opção | O que faz |
| --- | --- |
| **SIM** | Ativa a regra descrita acima. |
| **NÃO** *(padrão)* | Não aplica a regra. |
